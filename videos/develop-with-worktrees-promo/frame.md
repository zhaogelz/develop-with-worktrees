# 唯一视觉母版

全片沿用同一个项目、A 登录页、B 接口、C 文档。任务 A/B/C 的身份、颜色和顺序始终一致。画面先拥挤，随后分开，最后汇入检查。运动用于说明位置和状态变化。

| 项目 | 约定 |
| --- | --- |
| 背景 | 深蓝 `#102436` |
| 面板 | `#1A354B`，边线 `#61798E` |
| 正文 / 次要文字 | `#F4F7FA` / `#B6C7D6` |

| 检查通过 / 主项目保留 | 绿 `#A6E3BE` |

| 正文 | 系统中文无衬线，主要说明 36px，任务名 42px |
| 辅助信息 | 30–34px，仅放品牌、路径和状态 |

# 画面结构

- x=86..994 为内容宽度。
- y=140 是固定品牌和“流程示意”标记。
- y=264 起依次放阶段、两行大标题、一句说明、流程结构和一句结论。
- y=1568 是固定时间进度。y=1660 以下留空，避开平台操作区。
- 六幕共用同一母版和样式，写在 `index.html`。保留 HTML 文字和布局，图形用 CSS；不以图片替代文字。
- 不加入装饰网格、扫描线、随机终端日志、虚假按钮或模拟点击。

# 动效

每幕先读标题，再看任务动作，最后停读结论。进入使用 0.3–0.5 秒减速；不弹跳、不持续漂移。全片单一暂停 GSAP 时间线，可从任意时间直接定位。分幕可见性由 HyperFrames clip 控制，内部元素由时间线控制。
