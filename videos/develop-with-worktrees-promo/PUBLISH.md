## 小红书

标题：AI 都说写好了，最后还是你收拾？

正文：

一个改登录页，一个修接口，还有一个补文档。三个 Codex 聊天同时开工，听起来很省事，最后却可能留下一堆要你整理的改动。

我做了个 Codex 插件 DWW：给每个修改任务一份独立目录，做完后把这批改动合在一起检查，通过后再合回本地分支。聊天中断了，也有目标和进度记录可接着做。

分开做，能避免工作中的文件互相覆盖。合并仍可能有冲突，检查也可能失败；遇到问题就先保留现场，修好再继续。

适合一个人开几条 AI 聊天，或者小团队同时改一个项目。安装方法在仓库 README 里。

话题：`#AI编程 #Codex #独立开发 #Git #开源工具`

## B 站

标题：多个 Codex 同时写代码，怎么少收拾残局？36 秒看懂 DWW

简介：

DWW 是一个管理本地 Git 流程的 Codex 插件。这个视频用登录页、接口、文档三个任务，演示独立目录、任务记录、组合检查和冲突暂停。

每个任务分开修改，符合条件的一批改动一起检查，通过后再合回本地分支。视频为流程示意；实际检查由项目配置决定，任务也可能等待批次集成。

安装命令：

```text
codex plugin marketplace add zhaogelz/develop-with-worktrees --ref v0.5.0-beta.7
codex plugin add develop-with-worktrees@develop-with-worktrees
```

项目仓库：[develop-with-worktrees](https://github.com/zhaogelz/develop-with-worktrees)

标签：`AI编程` `Codex` `Git` `独立开发` `开发者工具`

置顶评论：你同时开几条 AI 聊天时，最费时间的是整理改动，还是处理合并后的问题？
