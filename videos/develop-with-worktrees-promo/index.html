DWWCodex 插件 / 流程示意
1 / 一起开工

AI 越开越多，
收尾全靠你？

页面、接口、文档，同时在改。

A改登录页写好了
B修接口也写好了
C补文档完成了
合起来，还能跑吗？

最后那一堆改动，又得你来理。

2 / 分开修改

给每个任务，
一张自己的桌子。

DWW 自动准备独立工作目录。

同一个项目
A
改登录页自己的目录
独立修改
B
修接口自己的目录
独立修改
C
补文档自己的目录
独立修改

各改各的文件，互不覆盖。

3 / 继续做事

各做各的。
进度也接得上。

换回这条任务时，有记录可接着做。

A
改登录页手机号登录
已提交
B
修接口处理登录超时
检查中
C
补文档补上使用说明
已提交
本地任务记录要做什么 · 做到了哪

中断之后，目标和进度还在。

4 / 一起检查

写完先别急。
放一起，跑一遍。

按你的项目配置检查组合后的改动。

A 登录页B 接口C 文档
这批改动，一起检查
合并改动通过
运行项目检查通过
合回本地分支

通过检查，再进入主项目。

5 / 遇到问题

有冲突，
就停在合入前。

合并冲突或检查失败，先保留现场。

Ⅱ登录页存在冲突本次合入已暂停
✓
两边的修改，都留着修好后再继续
主项目保持原样

停下来解决，不把问题带进主线。

6 / 开始使用

你管想法。
让改动有序落地。

分开做，一起检查，再合回去。
